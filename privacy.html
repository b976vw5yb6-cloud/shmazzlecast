Privacy policy

Last updated: 3 November 2026

ShmazzleCast is a personal tool used only by the owner of the ShmazzleTV YouTube channel on their own computer.

What it accesses

With the channel owner's permission (Google sign-in), ShmazzleCast uses the YouTube Data API to create, update and delete scheduled live broadcasts, bind them to the owner's stream key, set their thumbnails, and read the owner's own channel name.

Where data is stored

The Google sign-in token is stored only on the owner's computer. ShmazzleCast has no server, collects no data from anyone else, and does not sell, share or transfer any data. Public match schedules are read from oriondriftcompetitive.com.

Google API Services

ShmazzleCast's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, which stops all use of the YouTube data.

Contact

Questions: via the ShmazzleTV YouTube channel, youtube.com/@ShmazzleTV.
